Voxtile

話して入力する、日本語のための Mac アプリ

キーを押しながら話すと、カーソルの位置に文字が入ります。「えーと」などの言いよどみは取り除き、句読点を整えます。GitHub や TypeScript のような英語の用語は、英語のまま書きます。

インストール

  1. DMG ファイルを開くVoxtile-0.1.0.dmg をダブルクリックします。
  2. Applications に入れる開いたウインドウで、Voxtile のアイコンを、同じウインドウにある Applications フォルダへドラッグします。
  3. 起動するアプリケーションフォルダの Voxtile を開きます。Dock には出ず、画面右上のメニューバーにマイクのアイコンが出ます。

Apple の確認（公証）を受けたアプリなので、そのまま開けます。

最初の設定

初めて起動すると、設定画面の「権限」が開きます。次の 3 つを済ませてください。

  1. マイク「許可する」を押し、出てきた確認で「許可」を選びます。
  2. アクセシビリティ「許可する」を押すと、システム設定が開きます。一覧の Voxtile をオンにしてください。キーを押したことを検知して、カーソルの位置に文字を入れるために使います。
  3. 🌐キーを「何もしない」にするシステム設定 > キーボード の「🌐キーを押して」を「何もしない」に変えます。変えないと、Fn キーを押したときに絵文字や macOS の音声入力も一緒に動きます。
許可したのに動かないときは、メニューバーのアイコンから「Voxtile を終了」して、もう一度開いてください。メニューのいちばん上に「⚠️ 権限の設定が必要です」が出ていなければ準備完了です。

使い方

文字を入れたい場所（メール、Slack、メモなど）をクリックしてから、次のように使います。

fn を押したまま話す

キーを離すと、1〜2 秒で文字が入ります。いちばん基本の使い方です。

fn を素早く 2 回

キーを離しても録音が続きます（ハンズフリー）。もう一度押すと終わります。長く話すときに。

esc

録音中や処理中に押すと取り消します。何も入力されません。

話している間は、画面の下に聞き取った文字が出ます。最後に整えた文が入るので、途中の表示に多少の誤りがあっても大丈夫です。

設定でできること

メニューバーのアイコン > 「設定…」から変えられます。

  • 録音キー: Fn のほか、右 Option・右 Command・右 Control から選べます
  • 辞書: 会社名やサービス名など、決まった書き方で出したい言葉を 1 行に 1 語ずつ書きます。例: Notion、Kubernetes
  • 和文と英単語の間のスペース: 「GitHub の」のように半角スペースを入れるかどうか
  • アプリ別: 文字が入らないアプリがあったときに、入力の方法を変えます（困ったとき）

精度を上げる（任意）

そのままでも、Mac に入っている音声認識だけで使えます。無料で、声が外に送られることもありません。ただ、専門用語や早口の聞き取りは苦手で、「えーと」などの言いよどみもそのまま入ります。

次の 2 つのサービスの「API キー」を入れると、精度が大きく上がります。

サービス役割キーがないと
ElevenLabsMac の認識が自信のないときだけ、声を送って聞き取り直すMac の認識結果をそのまま使う
Anthropic（Claude）言いよどみを取り、句読点と表記を整える整えずにそのまま入力する

費用の目安

どちらも使った分だけの支払いで、料金は各サービスに直接払います。開発者の手元でのテストでは 1 回あたり約 0.07 円、1 日 100 回使って 月 200 円ほどでした（話す長さや内容で変わります）。

キーの作り方

ElevenLabs のキー
  1. elevenlabs.io でアカウントを作る
  2. ログインして、API Keys の画面でキーを作る
  3. 権限（Permissions）は Speech to Text だけオンにすれば十分です
  4. 表示されたキーをコピーする（あとから見られないので、その場で）
Anthropic のキー
  1. console.anthropic.com でアカウントを作る
  2. Billing でクレジットを購入する（最低額で十分です）
  3. API Keys で「Create Key」を押し、表示されたキーをコピーする

キーは、Voxtile の設定 > 「API キー」に貼り付けて「保存」します。キーは Mac のキーチェーンに保存され、ほかには送られません。

API キーはパスワードと同じです。人に見せたり、チャットに貼ったりしないでください。

困ったとき

Fn を押すと、絵文字の一覧や macOS の音声入力が出る

システム設定 > キーボード の「🌐キーを押して」を「何もしない」にしてください。文字が 2 回入るときも、これが原因です。

キーを押しても何も起きない

システム設定 > プライバシーとセキュリティ > アクセシビリティ で Voxtile がオンか確かめてください。オンなのに動かないときは、一度オフにしてからオンに戻し、Voxtile を起動し直してください。

文字が入らないアプリがある

入らなかった文はクリップボードに残るので、⌘ + V で貼り付けられます。そのアプリでは次から別の方法を自動で試します。設定 > 「アプリ別」で、方法を自分で選ぶこともできます。

短く押しただけでは何も入らない

素早く 1 回押すのは「2 回押し（ハンズフリー）」の 1 回目とみなすため、何も入力しません。少し長めに押してから話してください。ハンズフリーを使わないなら、設定でオフにできます。

パスワードの入力欄で反応しない

安全のため、パスワードの入力欄では録音しません。

アンインストールしたい
  1. メニューバーのアイコン > 「Voxtile を終了」
  2. アプリケーションフォルダの Voxtile をゴミ箱に入れる
  3. 履歴も消すなら、Finder で ~/Library/Application Support/Voxtile フォルダを消す
  4. API キーも消すなら、先に設定 > 「API キー」で「削除」を押しておく

送られる情報

  • 開発者は、あなたの声・文字・使い方のデータを受け取りません。開発者のサーバーはありません
  • API キーを入れたときだけ、あなたの Mac から ElevenLabs と Anthropic へ直接送られます
  • 声は、Mac の認識で十分に聞き取れたときは外に送りません
  • 履歴はあなたの Mac の中だけに保存し、30 日で自動的に消します。録音した声そのものは保存しません

外部に送るもの

送り先送るもの送るとき
ElevenLabs録音した声、辞書の単語Mac の認識の自信度が低いときだけ（設定で「常にクラウド」なら毎回、「常に端末内」なら送らない）
Anthropic書き起こした文字、入力先のアプリ名、辞書の単語清書が有効なとき、話すたび
Anthropic入力欄のカーソルの直前にある文字（最大 500 字）同上。文の続きとして自然につなげるため。設定の「カーソルの前の文を清書に使う」をオフにすると送らない

送った情報は、各社のプライバシーポリシーに従って扱われます: ElevenLabs / Anthropic

  • マイク: キーを押している間だけ録音する
